# دعوت‌نامه‌ی آنلاین جشن روز معلم

یک صفحه‌ی دعوت ساده و زیبا که نام هر مهمان را از روی لینک نمایش می‌دهد.
رایگان روی GitHub Pages اجرا می‌شود و به سرور یا پایگاه داده نیاز ندارد.

```
https://teslaoruz.github.io/invitation/?name=محمد-احمدی   ←  نام «محمد احمدی» نمایش داده می‌شود
https://teslaoruz.github.io/invitation/                   ←  «معلم گرامی» نمایش داده می‌شود
```

## فایل‌ها

| فایل | کاربرد |
|------|--------|
| `config.js` | **همه‌ی متن‌ها (عنوان، متن دعوت، تاریخ، ساعت، مکان، امضا) — فقط همین را ویرایش کنید** |
| `index.html` | صفحه‌ی دعوت‌نامه |
| `style.css` | ظاهر و رنگ‌ها (رنگ‌ها در بالای فایل) |
| `script.js` | خواندن نام از لینک (نیازی به تغییر ندارد) |
| `links.html` | ساخت لینک اختصاصی برای فهرست مهمانان |
| `fonts/` | فونت فارسی وزیرمتن |

## ۱. تغییر متن دعوت‌نامه

فایل `config.js` را باز کنید و متن‌های بین دو علامت `" "` را عوض کنید.
اگر بخشی را نمی‌خواهید، آن را خالی بگذارید (`""`) تا از صفحه حذف شود.

## ۲. بارگذاری در گیت‌هاب و فعال‌کردن GitHub Pages

۱. در <https://github.com> حساب رایگان بسازید و وارد شوید.
۲. بالای صفحه روی **+** و سپس **New repository** بزنید.
   یک نام بنویسید (مثلاً `invitation`)، گزینه‌ی **Public** را انتخاب کنید و **Create repository** را بزنید.
۳. روی **uploading an existing file** بزنید.
۴. همه‌ی فایل‌ها و پوشه‌ی `fonts` را به صفحه بکشید و رها کنید (فایل `index.html` باید در بالاترین سطح باشد، نه داخل پوشه‌ی دیگر).
۵. روی **Commit changes** بزنید.
۶. به **Settings** و سپس **Pages** بروید.
۷. در بخش **Source** گزینه‌ی **Deploy from a branch** را انتخاب کنید، شاخه‌ی **main** و پوشه‌ی **/ (root)** را بگذارید و **Save** را بزنید.
۸. یکی دو دقیقه صبر کنید و صفحه را تازه کنید. آدرس سایت بالای همین صفحه نمایش داده می‌شود:
   `https://teslaoruz.github.io/invitation/`

برای تغییرات بعدی، فایل `config.js` را در گیت‌هاب باز کنید، روی آیکون مداد ✏️ بزنید، متن را تغییر دهید و **Commit changes** را بزنید.

## ۳. ساخت لینک برای مهمانان

۱. صفحه‌ی `https://teslaoruz.github.io/invitation/links.html` را باز کنید.
۲. نام مهمانان را بنویسید، هر نام در یک خط.
۳. روی «ساخت لینک‌ها» و سپس «کپی همه» بزنید و لینک هر نفر را برایش بفرستید.

یا به‌صورت دستی: به انتهای آدرس سایت `?name=` و نام را اضافه کنید و به جای فاصله `-` بگذارید:

```
https://teslaoruz.github.io/invitation/?name=زهرا-کریمی
```
